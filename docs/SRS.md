# SRS.md — Software Requirements Specification
## Pasmh Work Management System (BWMS)
**الإصدار:** 1.0.0 | **التاريخ:** نوفمبر 2026

---

## 1. نظرة عامة

نظام BWMS هو منصة إدارة عمل داخلية لمؤسسة بصمة للأعمال الإنسانية، تُستخدم من قبل 8 موظفين لإعداد الخطط ومتابعة المهام وإعداد التقارير واعتمادها.

## 3. متطلبات وظيفية

### 3.1 المصادقة والأمان
- FR-AUTH-01: تسجيل دخول بالبريد وكلمة المرور
- FR-AUTH-02: JWT tokens (access + refresh)
- FR-AUTH-03: استعادة كلمة المرور بالبريد الإلكتروني
- FR-AUTH-04: تغيير كلمة المرور
- FR-AUTH-05: حماية جميع API Routes
- FR-AUTH-06: RBAC بمستوى API

### 3.2 الخطط
- FR-PLAN-01: إنشاء خطط يومية/أسبوعية/شهرية
- FR-PLAN-02: إضافة أهداف وأنشطة ونتائج متوقعة
- FR-PLAN-03: حفظ كمسودة
- FR-PLAN-04: إرسال للمراجعة
- FR-PLAN-05: اعتماد أو رفض أو إعادة للتعديل (مع سبب إلزامي)
- FR-PLAN-06: دورة اعتماد: مدير قسم → مدير تنفيذي (أو مباشرة للمدير التنفيذي)
- FR-PLAN-07: تاريخ الاعتمادات
- FR-PLAN-08: منع تكرار الخطة لنفس المستخدم والفترة
- FR-PLAN-09: أرشفة الخطط المعتمدة

### 3.3 المهام
- FR-TASK-01: إنشاء مهام شخصية
- FR-TASK-02: إسناد مهام لموظفين
- FR-TASK-03: تحديث حالة المهمة (pending/in_progress/completed/under_review/approved)
- FR-TASK-04: تحديث نسبة الإنجاز
- FR-TASK-05: إضافة تعليقات
- FR-TASK-06: رفع مرفقات (صور/PDF/DOCX/XLSX)
- FR-TASK-07: طلب مراجعة المهمة
- FR-TASK-08: اعتماد المهمة
- FR-TASK-09: سجل تعديلات كامل
- FR-TASK-10: المهمة لا تُعتبر مكتملة إلا بعد الاعتماد

### 3.4 التقارير
- FR-REP-01: إنشاء تقرير يومي تلقائي من بيانات مهام اليوم
- FR-REP-02: السماح للموظف بتعديل التقرير التلقائي
- FR-REP-03: منع إنشاء تقرير مكرر لنفس المستخدم والتاريخ
- FR-REP-04: إنشاء تقارير أسبوعية وشهرية يدوياً
- FR-REP-05: ربط التقرير بالمهام المنجزة
- FR-REP-06: دورة اعتماد مطابقة للخطط
- FR-REP-07: تصدير PDF
- FR-REP-08: التقرير التلقائي لا يُرسل أو يُعتمد تلقائياً

### 3.5 الاعتمادات
- FR-APP-01: دورة اعتماد: مسودة → مراجعة → اعتماد/رفض/إعادة
- FR-APP-02: سبب إلزامي عند الرفض أو الإعادة
- FR-APP-03: سجل كامل لجميع الاعتمادات
- FR-APP-04: منع الاعتماد الذاتي

### 3.6 الإشعارات
- FR-NOT-01: إشعارات داخلية
- FR-NOT-02: إشعارات بريد إلكتروني
- FR-NOT-03: عداد الإشعارات غير المقروءة
- FR-NOT-04: إشعار عند: إسناد مهمة، اقتراب موعد تسليم، تأخر مهمة، اعتماد/رفض خطة أو تقرير

---

## 4. متطلبات غير وظيفية

- NFR-01: RTL حقيقي، اللغة العربية الكاملة
- NFR-02: Responsive Design (جوال + كمبيوتر)
- NFR-03: أداء جيد مع 8 مستخدمين متزامنين
- NFR-04: أمان: لا secrets في الكود، HTTPS فقط في الإنتاج
- NFR-05: قابلية الصيانة: كود نظيف، modular
- NFR-06: منطقة زمنية: Asia/Aden

---

## 5. قيود التصميم

- لا تطبيق هاتف مستقل في النسخة الأولى
- الاستضافة مجانية في النسخة الأولى
- لا حذف نهائي للبيانات المعتمدة
- لا بيانات وهمية في الإنتاج
